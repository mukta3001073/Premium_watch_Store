# Premium Watch Store

A web-based e-commerce project for an online watch store.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv

## Completed Tasks
- Initialized Node.js project.
- Set up Express.js server.
- Connected MongoDB using Mongoose.
- Created User and Product models.
- Created User and Product API routes.
- Configured environment variables.
- Added `.gitignore` for sensitive files and dependencies.

## Project Status
**Partial Submission**

More features, including dynamic product display and automated welcome emails, will be implemented in the next phase.
